# Sprint Retrospective

## What went well?



- Use OpenAI API makes our life easier
- Use of docker for consistency.


## What changed from initial planning?

- Included OpenAI API in tests.
  - After listening to DHH podcasts, I became a believer of no mocking and pro integration tests. 
  - We only used 1 cent of openAI API despite the AI integrated tests.
- Blocked users from coding unless approved by AI (problem understanding, functional approach).
  - Made an observation that you always want to double check that you understand the problem and have a correct approach before coding no matter how confident you feel.

## What makes you mad?

- Limited problem set.
- Ugly integrated code editor.
- Ugly AI socratic chat interface.

## What do you think we can do better in the next sprint?

- Focus on the front-end and make quality of life changes.
